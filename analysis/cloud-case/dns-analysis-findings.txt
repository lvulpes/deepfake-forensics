# Deepfake Forensics DNS Traffic Analysis Report

## Overview
This report analyzes the DNS traffic in `dns-only.pcap` (`/home/hugin/code/deepfake-forensics/data/cloud-case/grok-2/evidence/dns-only.pcap`) captured on September 23, 2026, to identify probable websites used in:
1. **Searching for images**
2. **Generating the deepfake**
3. **Sharing the image on social media**

---

## Key Findings by Category

### 1. Image Search Phase
- **Domains Queried:** `www.bing.com`, `th.bing.com`
- **Purpose:** Used for web/image search (Bing Search engine and Bing Thumbnail image service).
- **DNS Queries & Resolved IPs:**
  - **`www.bing.com`**
    - *Query Time:* `2026-09-23 12:18:28 UTC+2` (and subsequent refreshes at `12:23:43`, `12:25:12`)
    - *Query Types:* A (1), AAAA (28), HTTPS (65)
    - *Resolved IPs:* Akamai CDN / Microsoft Traffic Manager IPs (e.g., `2.23.172.129`, `2.23.172.145`, `2.23.172.111`)
  - **`th.bing.com`**
    - *Query Time:* `2026-09-23 12:24:39.950 UTC+2`
    - *Query Types:* A (1), AAAA (28), HTTPS (65)
    - *Resolved IPs:* `92.123.135.71`, `92.123.135.82`, `2.23.172.111`, etc. (Akamai CDN)

### 2. Deepfake Generation Phase
- **Domains Queried:** `grok.com`
- **Purpose:** Accessed to utilize Grok (AI model by xAI) for image generation / chatbot interaction.
- **DNS Queries & Resolved IPs:**
  - **`grok.com`**
    - *Query Time:* `2026-09-23 12:18:28.586 UTC+2`
    - *Query Types:* A (1), AAAA (28), HTTPS (65)
    - *Resolved IPs:* Cloudflare Anycast IPs (e.g., `104.18.28.234`, `104.18.29.234`, `172.64.32.218`, `173.245.58.218`, `108.162.192.218`)

### 3. Social Media Sharing Phase
- **Domains Queried:** `x.com`, `api.x.com`, `upload.x.com`, `pbs.twimg.com`, `video.twimg.com`, `abs.twimg.com`
- **Purpose:** Used to access X (formerly Twitter), interact with the platform, upload media/images, and serve image assets (`pbs.twimg.com`).
- **DNS Queries & Resolved IPs:**
  - **`x.com`**
    - *Query Time:* `2026-09-23 12:23:14 UTC+2` (and recurring checks)
    - *Resolved IPs:* Cloudflare / Route53 / Twtrdns IPs (`172.66.0.227`, `205.251.192.179`, `204.74.111.101`)
  - **`upload.x.com`**
    - *Query Time:* `2026-09-23 12:23:50.034 UTC+2`
    - *Resolved IPs:* `172.66.0.227`, `205.251.192.179`, etc. (Dedicated endpoint for uploading media attachments like the deepfake image).
  - **`pbs.twimg.com`**
    - *Query Time:* `2026-09-23 12:23:44.550 UTC+2`
    - *Resolved IPs:* Fastly CDN IPs (`199.232.40.159`, `23.235.32.32`, `104.156.80.32`) (Used for photo/image hosting on X).
  - **`api.x.com`, `abs.twimg.com`, `video.twimg.com`**
    - *Query Times:* `12:23:18 UTC+2` (`api.x.com`), `12:23:14 UTC+2` (`abs.twimg.com`), `12:23:45 UTC+2` (`video.twimg.com`).

---

## Conclusion
The DNS traffic analysis confirms a clear progression of activity on `2026-09-23`:
1. **Search:** The user searched for reference images via Microsoft Bing (`www.bing.com`, `th.bing.com`).
2. **Generation:** The user queried `grok.com` (xAI) to generate the deepfake image.
3. **Sharing:** The user connected to X (`x.com`), uploaded the generated image via `upload.x.com`, and served media assets through `pbs.twimg.com`.
